# Loci font source files

These are the static TrueType source fonts for the Unity TextMeshPro atlases. The atlas files will be generated in Unity after TextMeshPro is available in the project.

| Family | Included weights | Source release | License |
|---|---|---|---|
| Inter | Regular (400), Medium (500), SemiBold (600), Bold (700) | [Inter 4.1](https://github.com/rsms/inter/releases/tag/v4.1) | SIL Open Font License 1.1; see `Inter/LICENSE.txt` |
| JetBrains Mono | Medium (500), SemiBold (600) | [JetBrains Mono 2.304](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304) | SIL Open Font License 1.1; see `JetBrainsMono/OFL.txt` |

The font archives were downloaded from the official upstream release pages. Inter 4.1 archive SHA-256: `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`; JetBrains Mono 2.304 archive SHA-256: `6f6376c6ed2960ea8a963cd7387ec9d76e3f629125bc33d1fdcd7eb7012f7bbf`.

The approved UI glyphs for the generated atlases include `→` (U+2192) and `✓` (U+2713), along with the project's ordinary English UI and code text. Keep each license with the corresponding font files when redistributing them.
